## Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Architecture | Pure shell scripts (drop Ansible) | Ansible is overkill for Homebrew + dotfiles + defaults |
| Dotfile manager | chezmoi | 1Password integration, templating, multi-machine support |
| Secrets storage | 1Password (via chezmoi templates) | Already in use, no encrypted files in repo |
| ZSH prompt | Starship | Fast, configurable, cross-shell, already in .config |
| Package management | Single Brewfile via `brew bundle` | Simple, native, supports taps/casks/MAS |
| OMZ replacement | Modular `~/.zshrc.d/*.zsh` files | 15 modules replacing OMZ plugins |
| Mackup | Drop entirely | chezmoi handles everything |
| Repo hosting | GitHub (public) | With secrets in 1Password, not in repo |
| Machine profiles | Interactive menu at runtime | All prompts upfront, then unattended |
| Bootstrap flow | Single script, pause for 1Password login | Phase 1 (core) -> pause -> Phase 2 (secrets) |
| Terminal tools | atuin, zoxide, eza, fzf, zellij | Replacing tmux, neofetch, standard ls/cd/history |

## Architecture

```
User runs bootstrap.sh (via curl | bash)
        |
        v
+-------------------------+
|   Interactive Menu       |
|   - Machine profile      |
|   - Hostname             |
|   - Module toggles       |
+----------+--------------+
           |
           v
+---------------------------------------------+
|  PHASE 1 (Unattended after menu)            |
|  1. Install Xcode CLI tools                 |
|  2. Install Homebrew                        |
|  3. brew bundle (Brewfile)                  |
|  4. Set hostname (if provided)              |
|  5. Apply macOS defaults                    |
|  6. Configure Dock via dockutil             |
|  7. Deploy non-sensitive dotfiles (chezmoi) |
|  8. ZSH configuration                       |
|  9. Create symlinks                         |
|  10. Configure Homebrew autoupdate           |
+----------+----------------------------------+
           |
           v
+--------------------------+
|  PAUSE                   |
|  "Sign into 1Password"   |
|  Wait for user confirm   |
+-----------+--------------+
            |
            v
+---------------------------------------------+
|  PHASE 2 (Unattended)                       |
|  1. Verify 1Password CLI auth               |
|  2. chezmoi apply (secrets - SSH keys etc)  |
|  3. Git signing configuration               |
|  4. Post-install validation + summary       |
+---------------------------------------------+
```

CLI flags: `--phase2` (resume after 1Password), `--unattended` (skip menu, use env vars/defaults)

## Verification Strategy

Each phase has its own validation checklist (detailed in the full plan at `.opencode/plans/migration-plan.md`). Key end-to-end tests:

1. **Fresh install test (VM):** curl one-liner -> personal profile -> all tools installed, dotfiles deployed, dock configured
2. **Idempotency test:** Run bootstrap twice -> no errors, no duplicates
3. **Phase 2 resume:** Run `--phase2` after 1Password sign-in -> secrets deployed, SSH works
4. **Module skip test:** Disable modules via menu -> disabled modules don't execute
5. **Profile test:** Each profile installs correct subset of tools
